# Accessibilité — journal

Objectif (CLAUDE.md) : balises ARIA, attributs `alt`, contrastes. Référence : WCAG 2.2 niveau AA.

## Audit

- **axe-core** (présent dans `node_modules`), injecté dans chaque page, Chrome headless.
- 7 pages (accueil, logement, à propos, 404, connexion, favoris, composants) × 2 largeurs (1440px, 390px).
- Règles : `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, `wcag22aa`, `best-practice`.
- Résultat : **0 violation**. Contrôle de l'outil : une image sans `alt` ajoutée volontairement est bien détectée.

## ARIA et sémantique

- `lang="fr"`, `<title>` unique par page, une hiérarchie de titres cohérente (un seul `h1`).
- Repères : `header`, `nav` nommées (« Navigation principale », « Navigation mobile »), `main`, `aside` (carte hôte), `footer`. Sections nommées par `aria-labelledby`.
- `aria-current="page"` sur la page en cours (header et menu mobile).
- Boutons composés d'une seule icône : `aria-label` (« Ouvrir le menu », « Fermer le menu »…). Liens icônes : texte `.visually-hidden` (« Favoris », « Messagerie »).
- Icônes décoratives en `aria-hidden="true"`.
- Bouton favori : libellé fixe (« Favori : {titre} ») + `aria-pressed` pour l'état.
- Menu burger : API Popover native (`aria-expanded` automatique, fermeture par Échap, clic extérieur).
- Textes destinés aux lecteurs d'écran : « Erreur 404 », « Note : 5 sur 5 ».
- Listes : `role="list"` conservé sur les `ul` sans puces (Safari).

## Images

- Toutes les images ont un attribut `alt`.
- Images informatives décrites (photo principale du logement, logo « Kasa — accueil »).
- Images décoratives ou redondantes avec un texte voisin en `alt=""` : photos des cartes (le titre suit), images d'ambiance, logo du footer, avatar à côté du nom de l'hôte.

## Clavier et interactions

- Lien d'évitement « Aller au contenu », visible au focus, sur toutes les pages (`main#contenu`).
- Focus visible : contour rouge de 2px (`:focus-visible`), y compris sur les champs de formulaire.
- Cartes : toute la carte est cliquable via le lien du titre ; le bouton favori reste au-dessus et accessible.
- Galerie mobile : rangée de vignettes défilante atteignable au clavier (`tabindex="0"` + `aria-label`).
- Cibles tactiles d'au moins 32×32px pour les liens icônes (≥ 24px exigés par WCAG 2.5.8).
- Formulaire de connexion : `label` associés, `type="email"`, `autocomplete`, `required`.
- `prefers-reduced-motion` respecté (transitions désactivées).
